# CinemaScope - Highest Hollywood Grossing Movies Analysis

CinemaScope is a comprehensive movie analytics platform that provides insights into Hollywood's biggest blockbusters through interactive visualizations and data analysis. The platform analyzes data from the highest grossing movies in Hollywood history, including box office performance, ratings, and production details.

## Features

### 1. Financial Analysis
- Budget vs. Revenue comparison
- ROI Distribution analysis
- Top performing movies by profit margin

### 2. Genre Analysis
- Genre distribution visualization
- Average ROI by genre
- Genre performance trends over time

### 3. Trend Analysis
- Box office trends (1997-2023)
- Seasonal performance patterns
- Budget evolution over time

### 4. Performance Metrics
- Rating vs. Financial Performance correlation
- Popularity impact analysis
- Performance correlation matrix

### 5. Studio Comparison
- Studio market share visualization
- Average ROI by studio
- Comprehensive studio performance comparison

### 6. Predictive Analytics
- Success probability model
- Feature importance analysis
- Performance prediction based on key factors

### 7. Movie Search
- Advanced search functionality
- Detailed movie information
- Comparative analysis with similar movies

## Technologies Used

- HTML5, CSS3, JavaScript
- Bootstrap 5 for responsive design
- Chart.js for data visualization
- AOS (Animate On Scroll) for animations
- Papa Parse for CSV data processing

## Data Sources

The platform uses data from "Highest Holywood Grossing Movies.csv" which includes:
- Box office performance data (domestic and international)
- Movie information and plot summaries
- Production details (budget, release date, etc.)
- Genre classification
- Distribution companies

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Explore the different modules and visualizations
